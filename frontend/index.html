Tournament Rules

Knockout formatEvery generated fixture is part of a single-elimination knockout bracket.
Verified players onlyOnly registrations with VERIFIED payment status enter the draw.
No drawsA knockout match must produce a winner. If needed, use the game's tie-break before submitting the final score.
ByesWhen the verified player count is not a power of two, eligible players can receive automatic first-round byes.
ResultsThe tournament admin records scores. Winners are automatically advanced to the next round.
Public resultsFixtures, scores and champions can be viewed publicly without signing in.

These rules reflect the current knockout system shipped with this Chuka Tournament Hub build.
